# Code of Conduct

We want a harassment-free, welcoming community. Be respectful, assume good faith, give and accept constructive feedback, and focus on what is best for the project.

Unacceptable: harassment, discrimination, personal attacks, doxxing, sexualised content, or sustained disruption.
